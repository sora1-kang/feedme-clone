한지원

AI에 보낼 때 앞에 붙일 프롬프트 (선택)

파일이 앱보다 오래 남는다는 말은 도구를 고르는 기준을 바꿔 놓습니다. 어떤 앱이 마음에 드는지를 묻기 전에, 그 앱이 사라진 뒤에도 내 기록을 열어볼 수 있는지를 먼저 묻게 되기 때문입니다.

저는 2014년부터 노트 1,284개를 쓰면서 앱을 네 번 바꿨습니다. 그중 지금도 아무 설정 없이 열리는 것은 37개뿐이었습니다. 나머지는 내보내기 기능이 없거나, 내보낸 파일이 원래 모양을 잃어버렸습니다.

다섯 가지 원칙

  1. 사람이 읽을 수 있는 형식으로 저장한다. 텍스트 편집기만 있으면 열려야 합니다.
  2. 한 노트는 파일 하나로 둔다. 데이터베이스 안에 숨기지 않습니다.
  3. 폴더 구조에 의미를 싣지 않는다. 의미는 파일 이름과 본문에 둡니다.
  4. 링크는 상대 경로로 쓴다. 폴더를 통째로 옮겨도 깨지지 않아야 합니다.
  5. 앱이 하는 일은 보기와 검색으로 제한한다. 기록 자체는 앱에 맡기지 않습니다.

도구는 바뀌지만 파일은 남습니다. 오래 쓸 기록일수록 도구보다 형식을 먼저 고르세요.
